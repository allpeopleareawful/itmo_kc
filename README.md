# ML Engineering — karpov.courses × ИТМО (AI Talent Hub)

Репозиторий с практическими заданиями, проектами и конспектами в рамках прохождения 9-месячной программы **[ML Engineering](https://karpov.courses/ml-engineering)** от karpov.courses и AI Talent Hub ИТМО.

## Структура репозитория
* **Ветка `main`** (текущая) — домашние задания, практика по Python, SQL, классическому ML, нейросетям и статистике.
* **Ветка [`final_project`](https://github.com)** — финальный проект курса: бэкенд-сервис персональных рекомендаций постов на FastAPI и PostgreSQL.
