# Сервис рекомендаций постов — Финальный проект (ML Engineering)

Финальный проект в рамках прохождения программы **[ML Engineering](https://karpov.courses)** от karpov.courses и ИТМО (AI Talent Hub). 

Это бэкенд-сервис персональных рекомендаций для социальной сети: он анализирует профиль пользователя и историю его действий в базе данных, прогоняет кандидатов через ML-модель и возвращает топ-N наиболее релевантных постов через API.

*(Домашние задания и практика по остальным модулям курса лежат в основной ветке [`main`](https://github.com/allpeopleareawful/itmo_kc/tree/main)).*
